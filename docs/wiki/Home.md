# NullLobby

Created by Kawaiipantsu for THUGS(red). NullLobby is being built as a RAM-first decentralized encrypted lobby chat client for authorized security work and internal coordination.

**Current release: Phase 1 offline foundations. No chat or network backend is available.** The Linux binary runs diagnostics only. No independent professional security audit has yet been completed.
